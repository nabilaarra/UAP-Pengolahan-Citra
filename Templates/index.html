    Tentang Aplikasi

    Aplikasi ini merupakan implementasi metode Gray-Level Co-occurrence Matrix (GLCM) untuk ekstraksi fitur tekstur citra digital tomat, dikombinasikan dengan algoritma klasifikasi K-Nearest Neighbor (KNN) untuk mengklasifikasikan kematangan tomat menjadi Ripe (Matang) atau Unripe (Belum Matang).

    Alur Sistem
    1
    Input Citra Tomat
    User upload foto tomat (JPG/PNG). Citra diterima oleh backend Flask dan disiapkan untuk pemrosesan.
    2
    Preprocessing
    Citra RGB dikonversi ke grayscale menggunakan OpenCV. Grayscale menghilangkan informasi warna agar analisis tekstur lebih fokus.
    3
    Pembentukan GLCM
    GLCM dibentuk dengan parameter: distance=[1], angle=[0°], levels=256, symmetric=True, normed=True.
    4
    Ekstraksi Fitur
    Dari GLCM diekstrak 4 fitur: Contrast, Correlation, Energy, dan Homogeneity menggunakan scikit-image.
    5
    Klasifikasi KNN
    KNN mencari K tetangga terdekat menggunakan Euclidean distance pada ruang 4 dimensi fitur.
    6
    Output Hasil
    Hasil prediksi (Ripe/Unripe) ditampilkan beserta confidence, nilai fitur GLCM, dan 3 tetangga terdekat.
    Formula Fitur GLCM
    Contrast = Σ (i-j)² · p(i,j) Correlation = Σ (i·j·p(i,j) - μᵢμⱼ) / σᵢσⱼ Energy = Σ p(i,j)² Homogeneity = Σ p(i,j) / (1 + |i-j|)
    Jarak Euclidean (KNN)
    d(x, y) = √(Σᵢ (xᵢ - yᵢ)²) Kelas mayoritas dari K tetangga terdekat = hasil prediksi Backend: Flask + scikit-image Frontend: Vanilla JS
    Cara Menjalankan Aplikasi
    # Install dependencies pip install flask flask-cors opencv-python scikit-image numpy pandas # Jalankan server python app.py # Buka browser http://localhost:5000
